Pepe Habla: game flow and app language

Mocked in Swedish so you can see the translated glosses. Buttons never move: every piece of feedback is a toast that drops in from the top. Dashed boxes under each phone describe what you hear. Nothing here changes the scheduling except point 6: a word only counts as right if the first tap was right.

A. A question, from start to finish (Swedish → Spanish)

question appears→🔊 “boken” (Swedish voice)→speaker icon fades in→tap “el pan”: 🔊 “el pan” → ✕ sound→“Försök igen!” for 2 s→tap “el libro”: 🔊 “el libro” → ✓ sound→3 s, or tap anywhere→next

The sound bars and the speaker icon share one fixed slot to the right of the word, so the word never shifts. The word and the icon are one tap target: tapping either one restarts the audio from the beginning.

8Settings: language

Added to the settings screen phase 2 is building. Each language is labelled in its own language, so you can always find your way back. Changing it applies immediately. It doesn't touch progress, which is stored per word.

New: an effects switch under Sound, shown off here. Off means no ✓/✕ sounds, no haptics and no chimes, but the voice still reads every word and every option you tap. The red and green toasts stay. The effects switch is only shown while Sound is on.
